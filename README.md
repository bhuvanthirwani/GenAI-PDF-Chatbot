# 🤖 GenAI PDF Chatbot

> **Interactive Document Assistant Powered by Generative AI**

**GenAI PDF Chatbot** is a modern web application that enables users to have natural conversations with their PDF documents. Built with **Next.js 13** and the **Vercel AI SDK**, it provides a seamless and responsive interface for extracting insights from documents in real-time.

## 🚀 Key Features

*   **💬 Real-time Chat**: Fluid streaming responses using the Vercel AI SDK.
*   **📄 PDF Context**: Intelligently parses and references PDF content during conversations (implied by name).
*   **🎨 Modern UI**: Clean, accessible interface built with Radix UI primitives and Tailwind CSS.
*   **⚡ High Performance**: Leveraging Next.js App Router for optimal speed and SEO.

## 📦 Getting Started

### Prerequisites

*   Node.js 18+
*   NPM or Yarn

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/yourusername/GenAI-PDF-Chatbot.git
    cd GenAI-PDF-Chatbot
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Setup Environment**
    Create a `.env.local` file and add your API keys (e.g., OpenAI API Key).
    ```bash
    cp .env.example .env.local
    ```

4.  **Run Development Server**
    ```bash
    npm run dev
    ```
    Open [http://localhost:3000](http://localhost:3000) to view the application.
